# Compact weather icons

Seven manually authored SVG icons matching the supplied minimal navy-outline and yellow-sun reference direction. Native 32 × 32 viewBox; render at 24–32 logical pixels. Transparent PNG companions at 96 × 96 pixels for 3× display. No filters, fonts, embedded bitmaps or external resources. Source reference remains unchanged. These are new sibling proposals, not exact traces of the reference raster.

sunny: sun; partly-cloudy: sun behind cloud; cloudy: two clouds; rain: cloud with rain strokes; storm: cloud and lightning; snow: cloud and snowflakes; fog: cloud with mist lines.

Prefer SVG for scalable assets; PNG is a convenience export. This folder is isolated and is not imported by the app. Earlier generated raster proposals are not promoted or substituted.
