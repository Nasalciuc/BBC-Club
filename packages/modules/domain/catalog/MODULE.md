# domain/catalog

**Owns:** schema `catalog.*` — `fares` (route/cabin/price catalogue), `airports` (IATA reference for pins + autocomplete), and `demand_daily` (UTC-day search counts, no member id).
**Publishes:** none on the journal. When `catalog.search_events` is on and `KAFKA_BROKERS` is set, `GET /v1/search` notes a route event that a flusher publishes to `bbc.search.v1`.
**Consumes:** `bbc.search.v1` on the worker (`APP_ROLE` not `api`), group `catalog.demand`, idempotent via `platform.kafka_processed`.
**Ports:** none (`needs: []`). Repository surface is the port — a Sabre / company-API adapter can replace `fares.repo` later without route changes.
**Facade:** `searchFares` (at most 30), `getFare`, `destinations`, `searchAirports`, `getAirport`, `getAirports`, `indicativeFor` (the estimate an undated search shows for a route, or null — requests asks it for a quote, ADR-IMPL-042), `importCsv`.
**Routes:** `GET /v1/search` (rate rule `search`), `GET /v1/fares/:id` (410 if past `valid_until` or unpublished, rate rule `read`), `GET /v1/airports?q=` (max 8, rate rule `read`), `GET /v1/airports/popular?from=` and `GET /v1/airports/home-suggestion?tz=` (rate rule `read`), `POST /v1/internal/catalog/import` (`catalog:import`), `GET /v1/internal/demand?days=7` (`ops:read`, no rate limit).
**Jobs:** `expire-fares` every 15 minutes — sets `published = false` where `valid_until < now()`, then clears the destinations cache. `demand-rollup` at 03:15 UTC writes yesterday's sketches into `demand_daily`.
**Home map:** `destinations()` is `DISTINCT ON (route_to)` ordered by price. Without Redis, a 60s process cache. With Redis, key `catalog:dest:{generation}:{HOME}` and `INCR catalog:dest:gen` on import and expire-fares, so every home misses without a SCAN. Airports use `catalog:airports:gen` the same way. A fare that expires mid-minute can stay on the map for ≤ 60s; its detail answers 410.
**Estimates:** `GET /v1/search` adds `estimate` (ADR-IMPL-037) when `catalog.estimates` is on and an undated search has no fare in the cabin: the company's formula, with the rules from the flag row `catalog.pricing_rules` (written by `scripts/load-pricing-rules.ts`; never in the repository). Missing or hand-edited rules → no estimate and `bbc_search_estimates_unavailable{reason}`; shown ones count in `bbc_search_estimates_shown{cabin}`. `indicativeFor` applies the same rule (one function) for a quote request and counts in `bbc_request_estimates_shown{cabin}` / `bbc_request_estimates_unavailable{reason}`; with estimates off it costs no query.
**Discovery** (ADR-IMPL-039): `popular` returns at most four destinations from `from` — the routes searched at least 5 times in the last seven UTC days (`demand_daily`, all cabins together), busiest first, then the hubs by `popularity`; never the origin or an airport under 100 km from it. Names only: a count never leaves the server. With Redis, cached 5 minutes under `catalog:popular:{airports gen}:{FROM}`. Until `catalog.search_events` is on and `demand-rollup` has run, it shows the hubs alone. `bbc_popular_destinations_shown{source="searches"|"hubs"}` counts what was shown. `home-suggestion` returns the busiest airport whose `tz` is the phone's zone or that zone's current name (`ZONE_ALIASES`: Android reports ICU names such as `Asia/Calcutta`); `null` for UTC or an offset; 400 when `tz` is not a time zone.
**Out of scope:** promotional offers (`proposals.offers`), Sabre adapter, mobile wiring.
**Invariants tested:** search JFK→LHR business → ≥3 · expired fare → 410 · airports `q=JF` ranks JFK · import idempotent · unauthenticated → 401 · timed fixture `arrive − depart == duration` · fa01 maps to 18:55 / 07:00 / +1 · same clocks under Europe/Chisinau and America/Los_Angeles · every `airports.csv` `tz` is IANA. Search events reject `memberId`, `ip`, and `deviceId`. Estimates: only without fares, never between one metro's airports or for an unconfirmed country, first only above business; the engine reproduces the reference results (`tests/parity`, CI secret). Discovery: searched ≥ 5 times in seven days first, then the hubs · never the origin or its metro · no count in the body · `Asia/Calcutta` → DEL, `Etc/UTC` → none · every airport `tz` is reachable from the name a phone reports.
