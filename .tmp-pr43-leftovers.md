## What / why

Squash-merge of #43 dropped three CodeRabbit fixes that were already written on `dev/charming-dirac-5iwixs` (`f6fdca0`, `2fc590a`). They never became ancestors of `main` (`4828680`). This PR cherry-picks them so ingest keeps the MODULE.md promise (same key + different payload → 409), lock-timeout tests wait for the lock instead of sleeping 200 ms, and the destructive-migration checker catches `DROP SCHEMA` and a final `DELETE` without a semicolon. Schema-parity also compares index columns and partial flags, not only names.

A third commit posix-normalizes `scripts/check-raw-sql-columns.ts` paths so `validate:quick` does not fail on Windows (`98 → 98` with backslash keys).
